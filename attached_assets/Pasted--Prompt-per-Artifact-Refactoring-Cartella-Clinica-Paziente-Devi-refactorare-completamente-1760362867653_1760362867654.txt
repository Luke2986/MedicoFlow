# 📝 Prompt per Artifact - Refactoring Cartella Clinica Paziente

```
Devi refactorare completamente la pagina di visualizzazione cartella clinica paziente per MedicoFlow, risolvendo problemi critici di UI/UX.

## CONTESTO ATTUALE

La pagina mostra le visite di un paziente ma ha gravi problemi:
1. Dropdown paziente nasconde informazioni critiche
2. Card visite troppo minimali (solo data + diagnosi)
3. Mancano alert medici sempre visibili (allergie, patologie croniche)
4. Nessun breadcrumb navigation
5. Validazione form permette salvataggio con "diagnosi: niente"
6. Info paziente (età, telefono, ultima visita) non visibili

## OBIETTIVO

Creare una pagina ottimizzata per uso clinico reale dove il medico vede IMMEDIATAMENTE:
- Header paziente fisso con dati essenziali (nome, CF, età, telefono)
- Alert box rosso se ci sono allergie/patologie critiche
- Card visite espanse con preview di diagnosi, terapia, anamnesi
- Quick actions facilmente accessibili
- Breadcrumb per tornare a lista pazienti

## STRUTTURA FILE DA CREARE

Crea un artifact con il file completo:
`app/dashboard/pazienti/[id]/page.tsx`

## REQUISITI TECNICI

### 1. DATA STRUCTURE
Il paziente ha questa struttura:
```typescript
interface Paziente {
  id: string
  nome: string
  cognome: string
  codiceFiscale: string
  dataNascita: Date
  telefono: string
  email?: string
  alerts?: string[]  // Es: ["Allergia penicillina", "Diabete tipo 2"]
  visite: Visita[]
}

interface Visita {
  id: string
  dataVisita: Date
  tipo: string  // "controllo", "prima-visita", "urgente"
  stato: string  // "completato", "programmato"
  durata: number  // minuti
  diagnosi?: string
  terapia?: string
  anamnesi?: string
  esameObiettivo?: string
  notePrivate?: string
  medicoId: string
  medicoNome?: string  // "Dr. Elena Rossi"
}
```

### 3. COMPONENTI DA USARE

- `lucide-react` icons: ArrowLeft, ChevronRight, AlertTriangle, Calendar, Phone, Mail, User, Stethoscope, Pill, FileText, Edit2, Trash2, Plus
- `date-fns`: format, formatDistance, differenceInYears
- `Link` da next/link per navigation
- Tailwind CSS per styling

### 4. FEATURES SPECIFICHE

#### A. Calcolo Età Automatico
```typescript
const età = differenceInYears(new Date(), new Date(paziente.dataNascita))
```

#### B. "Ultima visita X giorni fa"
```typescript
const ultimaVisita = visite[0] // array già ordinato desc
const giorniDaUltimaVisita = formatDistance(
  new Date(ultimaVisita.dataVisita),
  new Date(),
  { addSuffix: true, locale: it }
)
```

#### C. Alert Box Condizionale
Mostra SOLO se `paziente.alerts && paziente.alerts.length > 0`

#### D. Links Funzionali
- Telefono: `<a href="tel:+39333...">`
- Email: `<a href="mailto:email@...">`
- Breadcrumb: `<Link href="/dashboard/pazienti">`
- Nuova visita: `<Link href="/dashboard/cartella-clinica/nuovo?pazienteId={id}">`

#### E. Card Visite
- Ordinate per data DESC (più recenti prima)
- Preview testo con `line-clamp-2` Tailwind
- Link "Vedi cartella completa" → `/dashboard/cartella-clinica/{visitaId}`

### 5. COLORI E STYLING

- Alert box: `bg-red-50 border-l-4 border-red-500 text-red-900`
- Diagnosi box: `bg-blue-50 border-l-4 border-blue-600`
- Card visite: `bg-white border border-gray-200 rounded-lg hover:shadow-md`
- Headers: `text-gray-900 font-bold text-2xl`
- Labels sezioni: `text-xs font-semibold text-gray-600 uppercase`
- Actions: `text-blue-600 hover:bg-blue-50` (edit), `text-red-600 hover:bg-red-50` (delete)

### 6. RESPONSIVE

- Mobile: stack tutto verticalmente
- Desktop: layout a colonne dove appropriato
- Header paziente: sempre single column per leggibilità
