# 📄 Export PDF Cartella Clinica - Modello Medico-Legale Conforme

## OBIETTIVO
Implementare export PDF cartella clinica seguendo gli **standard medico-legali italiani**, con schema strutturato conforme a Decreto Ministeriale e linee guida professionali.

**Schema Conforme Include:**
- Intestazione completa ambulatorio/medico
- Dati anagrafici paziente completi
- Anamnesi strutturata (4 sezioni)
- Esame obiettivo con parametri vitali
- Diagnosi (con codice ICD-10 opzionale)
- Esami diagnostici prescritti/effettuati
- Terapia prescritta dettagliata
- Diario clinico e note evoluzione
- Consenso informato (riferimento)
- Firma digitale e timbro professionale
- Watermark sicurezza
- Metadati e tracciabilità

## 📄 FILE 1: Aggiorna Prisma Schema - Modello Strutturato

Aggiungi campi strutturati in `prisma/schema.prisma`:

```prisma
model CartellaClinica {
  id              String   @id @default(cuid())
  pazienteId      String
  paziente        Paziente @relation(fields: [pazienteId], references: [id], onDelete: Cascade)
  
  // Metadata visita
  dataVisita      DateTime
  tipoVisita      String   // "prima-visita" | "controllo" | "urgente"
  motivoAccesso   String?  @db.Text
  
  // ANAMNESI STRUTTURATA
  anamnesi_familiare     String?  @db.Text  // Patologie familiari rilevanti
  anamnesi_fisiologica   String?  @db.Text  // Abitudini, stile vita, allergie
  anamnesi_patologica_remota  String?  @db.Text  // Patologie pregresse
  anamnesi_patologica_prossima String?  @db.Text  // Sintomi attuali, storia recente
  
  // ESAME OBIETTIVO
  parametri_vitali  String?  @db.Text  // JSON: PA, FC, Temp, SpO2, etc
  esame_generale    String?  @db.Text  // Aspetto, stato nutrizionale, idratazione
  esame_apparati    String?  @db.Text  // Per apparato (cardiaco, respiratorio, etc)
  
  // DIAGNOSI
  diagnosi          String?  @db.Text
  diagnosi_icd10    String?  // Codice ICD-10
  diagnosi_differenziale String? @db.Text
  
  // ESAMI DIAGNOSTICI
  esami_prescritti  String?  @db.Text  // Esami richiesti
  esami_effettuati  String?  @db.Text  // Referti allegati
  
  // TERAPIA
  terapia_farmacologica    String?  @db.Text  // Prescrizioni farmaci
  terapia_non_farmacologica String? @db.Text  // Fisioterapia, dieta, etc
  
  // DIARIO CLINICO
  note_cliniche     String?  @db.Text  // Evoluzione, follow-up
  piano_terapeutico String?  @db.Text  // Piano di cura
  prossimo_controllo DateTime? // Data controllo successivo
  
  // CONSENSO
  consenso_firmato  Boolean  @default(false)
  consenso_data     DateTime?
  
  // ALLEGATI
  allegati          Json?    // Array di file paths
  
  createdAt         DateTime @default(now())
  updatedAt         DateTime @updatedAt
  createdBy         String   // ID medico
  
  @@index([pazienteId])
  @@index([dataVisita])
  @@index([createdBy])
}
```

Esegui migrazione:
```bash
npx prisma migrate dev --name cartella_clinica_strutturata
npx prisma generate
```
